# Roadmap

This roadmap represents the current planned progression of the project. Milestones focus on delivering demonstrable functionality rather than technical implementation details.

---

# Milestone 1 - Hello Course

Goal: Upload and manage course packages.

Success Criteria:

- Upload a SCORM package
- Store package metadata
- View available courses
- Delete uploaded courses

Demonstration:

A user can upload a course and see it available within the platform.

---

# Milestone 2 - Launch Course

Goal: Play course content.

Success Criteria:

- Extract uploaded packages
- Launch course content
- Display content within a training player
- Support basic SCORM runtime communication

Demonstration:

A user can launch and interact with course content.

---

# Milestone 3 - Progress Tracking

Goal: Persist learner state.

Success Criteria:

- Save learner progress
- Save suspend data
- Resume a course from a previous session

Demonstration:

A learner can exit a course and later continue where they left off.

---

# Milestone 4 - Course Completion

Goal: Track completion outcomes.

Success Criteria:

- Record completion status
- Record pass/fail status
- View learner completion history

Demonstration:

A learner can complete a course and the platform records the outcome.

---

# Milestone 5 - Multi-User Support

Goal: Support individual learner accounts.

Success Criteria:

- User authentication
- User-specific progress tracking
- User course history

Demonstration:

Multiple users can independently complete the same course.

---

# Milestone 6 - xAPI Foundation

Goal: Support modern learning activity tracking.

Success Criteria:

- Generate xAPI statements
- Store activity history
- View learner activity records

Demonstration:

Learning activities are available through xAPI-compatible records.

---

# Milestone 7 - Public Release

Goal: Make the platform consumable by others.

Success Criteria:

- Installation documentation
- Docker deployment support
- Public GitHub release
- Initial contributor guidance

Demonstration:

A third party can install and run the platform.
