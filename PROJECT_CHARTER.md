# Open Training Platform - Project Charter

## Purpose

Build an open-source training content platform focused on course content management and standards-compliant course playback.

The primary goal is personal enjoyment, learning, and consistent progress.

The project does not need to generate revenue.

## Success Criteria

Success is defined as:

- Consistently working on the project
- Releasing incremental functionality
- Learning new things
- Building something I personally find useful and interesting

Success is NOT defined as:

- Perfect architecture
- Enterprise-grade scalability
- Large user adoption
- Commercial viability

## Guiding Principles

1. Working software over ideal software.

2. Features before infrastructure.

3. Architecture may evolve through learning.

4. Refactoring only occurs when:
   - A bug exists
   - A feature is blocked
   - Development speed is significantly impacted

5. Ideas for improvement are captured in the backlog, not implemented immediately.

## Initial Scope

In Scope:

- Course upload
- Course storage
- Course launch
- Course playback
- Progress tracking

Out of Scope:

- LMS functionality
- Certifications
- Advanced reporting
- Multi-tenancy
- Billing
- Marketplace features

## Exit Criteria for Version 1

A user can:

1. Upload a SCORM package
2. Launch a course
3. Complete a course
4. Persist completion status

At that point Version 1 is considered successful.
